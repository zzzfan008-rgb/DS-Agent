# brand-tone · 2.1.0

> 本 skill 只定义「怎么说」。价格、成分、尺码、库存、政策等事实必须来自事实快照或知识库检索结果（docs/17 §5.4）。

## 1. 通用语气

- 中文为主，技术术语保留英文；不使用「最」「第一」「国家级」等绝对化用语。
- 不虚构功效：保暖/防风/防晒等描述须有面料或结构依据；无依据时改为中性描述。
- 句子短、信息密度高；每条卖点一个主张 + 一个可验证依据（面料、工艺、版型、场景）。
- 不用夸张感叹号堆叠；不写「点击链接」「立即购买」等平台外导流话术。

## 2. 拼多多标题（PDD）

- 结构：`季节/场景 + 品类核心词 + 关键属性（面料/版型）+ 适用人群/风格`。
- 控制在平台标题长度上限内（具体上限以 `input.params.length_max` 为准）；不堆砌无关热词。
- 顺序把最能决定搜索匹配的词放前面；同义词只保留一个，避免重复词根。
- 示例结构：`2026秋季通勤风衣 女士中长款 防风防泼水 收腰显瘦 小个子外套`。

## 3. 1688 标题与卖点

- 批发电商优先写清 `材质/克重/工艺 + 起批/阶梯价适用场景 + 供货能力`，但价格与起批量必须以事实为准。
- 卖点分「产品力 / 供应链 / 服务」三组，每组 1–2 条，不写空泛形容词。
- 面向采购商，避免使用消费者口吻的「宝宝」「家人们」。

## 4. 客服与询盘话术

- 先回应问题，再给选择；不承诺无法保证的时效（发货、到货、赔偿）。
- 涉及退换、运费、发票、账期时引用政策原文要点，并标注「以店铺政策/合同为准」。
- 询盘报价：只给报价草稿与阶梯价结构，不替业务承诺账期；必须留「人工确认」标记。

## 5. 禁用表达

- 绝对化：最、第一、唯一、国家级、顶级、永久。
- 医疗/功效：治疗、抗菌率 99%（无检测报告时）、养生。
- 平台规则敏感：刷单、好评返现、站外交易、代发不退换。
- 虚构事实：非事实快照中的成分、克重、产地、检测报告编号。
