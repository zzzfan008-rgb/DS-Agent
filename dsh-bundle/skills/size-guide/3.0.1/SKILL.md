# size-guide · 3.0.1

> 尺码事实只来自 `size_chart`（一尺码一行，`effective` 版本）与商品 SKU 的 `size_code`（docs/06、docs/19、docs/21 §6）。本 skill 只说明「怎么量、怎么解释、怎么表述」。

## 1. 测量口径

| 字段键 | 中文名 | 量法 |
|---|---|---|
| `bust_cm` | 胸围 | 腋下水平一周，贴身但不勒紧 |
| `shoulder_cm` | 肩宽 | 后背两肩骨端点直线距离 |
| `sleeve_cm` | 袖长 | 肩点沿袖外侧至袖口 |
| `length_cm` | 衣长 | 后领中点垂直至下摆 |
| `waist_cm` | 腰围 | 腰部最细处水平一周 |
| `hip_cm` | 臀围 | 臀部最丰满处水平一周 |
| `thigh_cm` | 大腿围 | 大腿根部水平一周 |
| `pants_length_cm` | 裤长 | 腰头沿外侧至裤脚 |
| `height_cm` / `weight_kg` | 建议身高/体重 | 选码参考区间，不是人体测量值 |

- 单位统一 cm；允差通常 ±1–2cm，须以尺码表 `measurements` 中声明为准。
- 测量方式（平铺/围量）必须与尺码表声明一致；未声明平铺时默认「成衣围量」。
- 不把「建议身高体重」当作硬性适配；体型差异大时优先围度。

## 2. 选码解释规则

1. 先看围度差值：胸围/腰围/臀围的「净体 + 松量」是否落在该码区间。
2. 再看版型：宽松（+8cm 以上松量）、合身（+4–6cm）、修身（+2–4cm）。
3. 最后看身高体重建议区间作为校验，不作为唯一依据。
4. 卡在边界时建议大一码；无该码或数据缺失时明确说明缺什么，不猜。

## 3. 表述规范

- 「模特 168cm/48kg 穿 M 码」这类信息必须有事实来源；无来源不写。
- 不写「均码适合所有人」；均码也必须给范围。
- 尺码表与 SKU 尺码不一致时，先报事实冲突，不自行合并。

## 4. 常见驳回诊断（listing.diagnose）

- 尺码表缺列 / 单位写成 inch 未标注 → 补齐或标注。
- SKU 尺码在尺码表中不存在 → 主数据修复，不改文案蒙混。
- 同一商品多版本尺码表并存 → 只能引用 `effective` 版本。
