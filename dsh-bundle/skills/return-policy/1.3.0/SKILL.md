# return-policy · 1.3.0

> 本 skill 只规定「如何引用与表达政策」，不替代店铺政策原文。检索不到政策条目时，明确说「需人工确认」，不得自行承诺。

## 1. 引用规则

1. 先检索知识库中的店铺/平台政策条目；引用时写明「依据：<文档名> v<版本>」。
2. 平台规则与店铺政策冲突时，以对消费者更有利且平台强制的一方为准，并提示人工复核。
3. 政策未覆盖的情形（定制、剪标、影响二次销售、超时）→ 升级人工，不即兴裁决。

## 2. 常见场景表述

| 场景 | 可表述 | 必须人工确认 |
|---|---|---|
| 七天无理由 | 自签收次日起 7 天内、商品完好可申请；以平台规则为准 | 是否影响二次销售、吊牌/包装是否齐全 |
| 质量问题 | 拍照留证 → 审核 → 退换/补偿方案 | 补偿金额、是否免运费 |
| 尺码不合适 | 建议按尺码表复测；可换码（视库存） | 换码运费承担、库存 |
| 物流破损/丢件 | 引导拒收或拍照报备，走平台理赔 | 赔付标准 |
| 1688 批发退换 | 按合同/约定与起批量条款处理 | 账期、扣款、返修责任 |
| 定制/改标 | 一般不适用无理由 | 全部条款 |

## 3. 话术结构

```text
结论（能不能退/换/赔）
→ 依据（平台规则或店铺政策条目）
→ 操作步骤（用户要做什么、需要什么材料）
→ 时效（多久内处理/到账）
→ 不确定项：需人工确认
```

- 不承诺具体到账时间（银行/平台处理时长不可控）。
- 不引导站外交易、不诱导撤诉/改评价。
- 不泄露其他客户信息或内部审批意见。

## 4. 禁止

- 「肯定能退」「百分百赔偿」等绝对承诺。
- 未经审批的补偿金额、免单、赠品承诺。
- 用「平台规定」含糊代替具体条目。
