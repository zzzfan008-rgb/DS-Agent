# care · 1.1.0

> 面料成分只来自 `fabric_composition`（合计 100%，docs/06），洗护结论应可由成分推导；无成分数据时只给通用建议并标注缺失。

## 1. 成分 → 洗护推导（常用）

| 成分 | 建议 | 注意 |
|---|---|---|
| 棉 ≥ 95% | 机洗 30℃ 以下，中性洗涤剂 | 易缩水，首次冷水单独洗；避免高温烘干 |
| 羊毛 ≥ 30% | 手洗/羊毛档冷水，平铺阴干 | 禁漂白、禁拧干、禁高温烘干 |
| 真丝 | 手洗冷水或专业干洗 | 中性洗剂，阴干，低温熨烫垫布 |
| 聚酯纤维 / 锦纶 | 机洗 30–40℃，常规 | 易起静电，少烘干；避免高温熨烫 |
| 粘纤 / 醋酸 | 手洗或干洗，低温 | 湿强低，不拧干；悬挂易变形，平铺 |
| 氨纶混纺 | 低温洗涤，不高温熨烫 | 弹性纤维怕热、怕氯漂 |
| 羽绒 | 专用洗剂，轻柔机洗/手洗，低温烘干拍松 | 忌干洗（部分涂层），彻底干燥防霉 |

- 成分合计不足 100% 或缺失 → 不推导具体洗护，只提示「成分待补全」。
- 拼多多/1688 平台要求洗护标注的，按平台类目规则输出；规则以 `platform.rules` 工具/知识库为准。

## 2. 表述模板

```text
洗护建议：30℃ 以下中性机洗；深浅分开；不可漂白；悬挂阴干；低温熨烫。
（依据：棉 95% / 氨纶 5%）
```

- 只写可执行动作，不写「小心呵护」这类无信息量表达。
- 涉及不可逆风险（羊毛毡化、真丝泛黄）时用「不可/禁止」明确表述。

## 3. 禁用

- 不编造检测报告、抗菌/防螨/UPF 等未经检测的功效。
- 不把「可机洗」写成「随便洗」；不承诺「不起球/不褪色」等绝对结果。
