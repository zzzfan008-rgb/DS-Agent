## 3. 核心规则实现（与 docs/07 对齐）

1. **可见性四条规则**（`policy.checkVisibility`）
   - R1：`provider.credential_ref` 非空 + `credential_ref.status='active'` + `provider.status='active'` + `connectivity='ok'`；
   - R2：`model.status='published'` + `published_at<=now` + `params_schema` 合法 + `default_params` 通过自身 schema；
   - R3：`route.status='active'` + 生效窗口 + scope 命中（user > role > org，role 用 roleIds 匹配）；
   - R4：角色 × 用途矩阵（viewer 无调用用途，operator=copy/judge/image/video，admin=全部）；
   - 附加：capability×purpose 兼容且 `purpose ∈ model.purpose_support`，否则 `model_purpose_mismatch`。
2. **路由解析**：scope 精度 → priority 升序 → updated_at 降序；候选 = `[model_id, ...fallback_ids]`；`judge` 最多 1 次降级，`embed` 不降级（硬编码）。
3. **配额**：`min(provider.rate_limit, model.rate_limit, route)`；rpm/tpm 60s 滑动窗口、concurrency 信号量、daily_calls/daily_cost_cents/monthly_cost_cents 用 `model_call_log` 聚合；超配额允许降级到「不更贵」的候选并标 `quota_fallback`，否则 `quota_exceeded`。
4. **降级**：只沿 `fallback_ids`；连接超时/5xx/429 可降级；400/401/403/404 不降级；每次尝试都写 `model_call_log`（失败 `cost_cents=0`），降级写 `audit_log(action='model.fallback')`。
5. **计量**：文本 `ceil(in*in_rate/1000)+ceil(out*out_rate/1000)`；图片按像素优先、否则按张；视频 `ceil(seconds*rate)`；嵌入 `ceil(tokens*rate/1000)`；rerank 复用 text 段；全整数分，调用时价目写入 `price_snapshot`。
6. **熔断**：60s 窗口失败率 ≥50% 且样本 ≥10，或连续 5 次超时 → 打开 60s；键 `modelId:model.version`；半开探针成功闭合、失败指数退避（上限 600s）。
7. **文本侧**：OpenAI-compatible 直连（docs/04 §6.3），`provider.base_url` + `Authorization: Bearer`；凭据按请求从 `credential_ref` 名称解析，M1 用 `DSSAAS_MODEL_CREDENTIALS`（生产换 DSH 凭据）。`dsh-llm-pi-ai` 只出现在配置/文档，不被 import（docs/04 Z6）。
8. **审计**：provider.create/update/test、model.create/update/price_change/test/publish/suspend/archive、route.create/update/publish、model.fallback 全部落 `audit_log`（经 t2 的哈希链）。

## 5. 关键计数/口径示例

- 文本计费：`in=1500, out=500`，价 `100/200 分每 1k` → `ceil(1500×100/1000)=150` + `ceil(500×200/1000)=100` = **250 分**（测试断言）。
- 改价后：`in=10, out=5`，价 `10/20 分每 1k` → `ceil(0.1)+ceil(0.1)=1+1= **2 分**。
- 配额取严：route `dailyCalls=5` / provider `daily_calls=9` → `dailyCalls=5`；route `rpm=10` / model `rpm=2` → `rpm=2`。
- 审计：`model.fallback` 的 `after={route_id, from_model_id, to_model_id, purpose}`；`model_call_log.fallback_from_model_id` 同步落库。

## 8. 与 t8/t9 的接口

- 调用方只传 `purpose`（copy/judge/image/video/embed/rerank），不传 `model_id`；`ModelGateway.invoke()` 返回 `decision{routeId, modelId, providerId, degraded, fallbackFrom, reason}` + `usage/costCents/callLogId`。
- `judge` 用途最多 1 次降级；`embed` 不降级（知识库走关键词降级，docs/09）。
- 每次调用必写 `model_call_log`（I2）；判断层/文案/素材通过 `subject_type/subject_id/prompt_version` 归集成本。
- `GET /models` 的可见性结果与调用解析共用 `checkVisibility`，避免「页面能看、调用失败」。
- kill switch 与写入门在 t8/t9 接入时，需在 `resolveRoute` 前追加闸门（L8）。
