## 已确认的设计决定

- **视觉方向**：深色侧栏 `#0F172A` + 浅色工作区 `#F8FAFC`（用户确认）。
- **风险编码**：A 可逆=绿、B 不可撤回=琥珀、C 不可逆=红；每级**颜色 + 图标 + 文字**三重编码，不单靠颜色区分（色盲可用）。
- **C 级不可逆**：详情页固定红色横幅，文案明确"不可撤回、不提供回滚、建议执行窗口"，操作按钮 disabled 并标注"M4 接入"。
- **事实来源**：以标签形式平铺，且要求必须可点击回溯（`docs/13` D2）。
- **演示数据**：页面右上角 `演示数据` 徽标；只在 API 404 时回退，网络/5xx 不回退。
