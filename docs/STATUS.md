## 已修复的真缺陷

| 缺陷 | 影响 | 修法 |
|---|---|---|
| `uq_size_chart_effective` 建在 product_id | 多码商品无法创建 | 改 `EXCLUDE USING gist` |
| 两份 `canonicalJson` 语义不同 | facts_hash 与 idempotency_key 可能算出不同值 | 统一到一份实现 |
| `fabric_id` 指向版本化面料行 | 面料升版导致 SKU 身份变化 | 改稳定 `fabric_code` |
| `uq_approval_open` 含 approved | 批准后无法重提审批 | 改为仅 `pending/scheduled` |
| 编辑草稿偷偷作废旧审批 | 掩盖"内容变了" | 旧审批保留，decide 时 428 |
| canonical 拒绝小数 | 半码商品 500 | 约束退回 schema 层 |
| `listProducts` 无 take/skip | 10,000 条 p95 886ms | 分页下推 + 批量扫描早停 |
| 连接池耗尽报 500 | 客户端不重试、值班误判 | P2024 → 503 + retryable |
| `drift_by_kind` key 不校验 | 配错则永不告警 | 启动时 fail fast |
| L1 禁词不识别否定 | "不能承诺当天发货"被误判 | 否定语境识别（L0 不豁免） |
| 静态门禁漏 `.tmp` | 临时产物导致误报 | 加入 SKIP_DIRS |
| 测试库并发 reset | 互相 DROP 表 | 并发验证 A/B 各全绿 |
