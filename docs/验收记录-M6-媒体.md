## 5. 状态机 / 幂等 / 成本

- **状态**（落库值，06 的 9 值）：`queued`（待提交）→ `submitted`（已拿 external_job_id）→ `polling`（退避轮询）→ `retrieved`（供应商成功）→ `succeeded`（资产已建）；失败 `failed`（`error_class`），超时 `expired`，取消 `cancelled`。`stored` 是内部阶段（建资产与成功同一次推进）。
- **退避**：`delay(n)=min(base·2ⁿ,cap)·(1+jitter)`；测试断言 2s→4s→8s（注入时钟与固定随机数，无真实 sleep）。
- **幂等三层**：provider `idempotencyKey` → 同一 external id；`media_asset.mediaJobId` → 只建一次；`cost_ledger(ref_type=media_job, ref_id=job_id)` → 只记一次。
- **成本**：图片 `amount_cents=供应商 usage.costCents`；渲染 `amount_cents=0, seconds=0.5`（render_seconds 口径）；视频预留 `seconds=duration_seconds`。`tokens` 暂为 0（媒体按张/秒计费，无 token）。
- **配额**：`media_quota` 按 org + sku + 时间窗取行；`usedImages >= maxImages` → 任务置 `failed/error_code=quota`，抛 `QuotaExceededError`（可读文案「媒体配额已用完（x/y 张/日）…」）。

## 6. 已知限制（必须与真实厂商/MinIO 联调前处理）

1. **mock provider**：`MockMediaProvider` 只在内存中模拟提交/轮询/取回；真实厂商（model id/凭据/限流）尚未接入。
2. **MinIO 未实机联调**：本机 `docker pull minio/minio` 被拒（无 registry 权限），因此用 `FsStorage` 产出样例 + 本地假 S3 服务验证 `S3Storage` 的 path-style 与 SigV4 头；`ensureBucket` 已实现但未在真实 MinIO 上跑过。上线前需在 `infra` 起 MinIO 并创建三桶。
3. **桶命名与 docs/10 的差异**：任务口径为 `media` / `media-variants` / `media-raw` 三个桶；`docs/10 §6.1` 写的是单桶 `dssaas-media` + `raw/derived/...` 前缀。本实现按任务三桶，桶名可用 `MEDIA_BUCKET` / `MEDIA_VARIANTS_BUCKET` / `MEDIA_RAW_BUCKET` 覆盖；需要文档裁决后统一（未改 docs/10）。
4. **未接 BullMQ delayed job**：当前为进程内轮询（`MEDIA_WORKER_ENABLED=1` + 5s tick）。`docs/10 §5.3` 要求用 BullMQ delayed job 且每 job 仅 1 个待触发任务；多实例部署会出现重复推进（需 Redis 锁/BullMQ 化）。
5. **取消清理时序**：API 只把状态置 `cancelled`；临时对象由 worker 下一 tick 清理（≤5s）。取消时未从 API 直接调用 provider.cancel（worker 侧 cancel 方法已实现）。
6. **视频未实现**：无 ffmpeg/转码；`purpose=video` 目前无真实产物（变体只覆盖图片）。任务也标注视频转码未做。
7. **字体与 XMP**：尺码表使用系统字体（Windows 实测中文正常），未按 docs/10 §8.3 随镜像打包思源黑体；AIGC 只做可见标识，未写 XMP `AIGC=true`（sidecar `meta.json` 亦未落 MinIO）。
8. **配额行需预先存在**：`media_quota` 没有自动发放（无默认行时视为不限）；`/media/generate` 创建任务与配额预检不在本任务（t9/后续）。
9. **API 取消路由未做集成测试**：依赖登录态与 DB；本次只通过 typecheck，逻辑含 404/409/终态幂等分支。
10. **sharp 原生依赖**：worker 新增 `sharp@0.35.5`（libvips 预编译包，Windows/Linux 均有），镜像体积增加约 30MB；已通过 pnpm 离线安装。
