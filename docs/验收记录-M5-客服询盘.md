## 3. 入站事务与去重（docs/18 §1.4）

`POST /internal/conversations/simulate-inbound`：

1. 找/建 `conversation`（platform + platform_conversation_id）；`buyer_ref` 只存 sha256，不存昵称明文（buyer_nick 为展示字段，可空）。
2. 单事务：
   - `INSERT message`：direction=inbound、platform_message_id、content、sent_at、status=received；
   - `UPDATE conversation SET unread_count = unread_count + 1, last_message_at, last_inbound_at`（Prisma `{ increment: 1 }`，不做读-改-写）；
   - `INSERT events_outbox(topic=message.created)`。
3. 提交后才 `hub.publish('message.created')`；ACK 不等 SSE/草稿。
4. 唯一键使用 t19 迁移后的 `(conversation_id, platform_message_id)`；冲突返回 200 `deduped=true`，不再累加未读、不写 outbox。

schema 无 `message.platform`，平台取 `conversation.platform`；无 `read_at`，已读只维护 `conversation.unread_count`。

## 4. SSE 秒级提醒（docs/18 §2）

- `GET /api/events/stream` 使用 cookie 会话鉴权（t2 auth gate），`reply.hijack()` 后写：
  - headers：`text/event-stream`、`Cache-Control: no-cache, no-transform`、`X-Accel-Buffering: no`；
  - 首帧 `retry: 3000`；
  - 连接即发 `unread.snapshot`（server_ts、total_unread、各会话 unread、snapshot_event_seq）；
  - `Last-Event-ID`（header 或 `last_event_id` query）用 `hub.replay()` 重放最近 1000 帧；空洞/过期/非法/超前 → `resync`（reason=gap/expired/unknown_id/ahead），前端应清空增量并拉快照；
  - 事件 `message.created` / `draft.updated` / `approval.pending`；`topics` query 可过滤 message/draft/approval/all；
  - 15s 注释心跳 `: hb <iso>`，不占 seq、不写 outbox；
  - 客户端断开/写失败清理 interval 与订阅。
- 事件同时写 `events_outbox`（inbound/reply/draft/approval）；M5 的消费端是进程内 hub，outbox 供后续 worker/多实例 Redis 扇出。
- **t24 已对齐**：`Last-Event-ID` 从 Postgres `event_log.seq` 重放（重启/跨实例可读）；进程内 ring 只用于本实例实时扇出。`event_log.seq` 是事件级游标，`message.event_seq` 是消息级序列，两者不混用；消息排序/`messages_after` 使用 `message.event_seq`。

## 5. 草稿 5 秒硬超时（docs/18 §3）

`POST /api/replies/draft`：

- `deadline_ms` 默认 5000，范围 50–5000（测试可缩短）；用 `Promise.race` 硬截止，超时立即返回，不抛错；迟到的模型结果丢弃。
- 事实/证据：
  - `fact_refs` 有值 → 逐条生成 `evidence_refs`（source_table/source_id/source_version/quote）；
  - 否则若会话有 `related_product_id` → `buildProductFacts()` 取价格/库存/成分/尺码等；
  - 无任何证据：**不调用模型**，直接 `degraded=true, degraded_reason=no_evidence` + 模板，提示人工确认。
- 模型：`gateway.invoke(purpose=copy)`；失败/无路由 → `model_error`；超时 → `timeout`；两者均落模板。
- 模板选择：`reply_template` 按 platform+intent（unknown 退 general）+ status=approved + weight/updatedAt 排序取 Top-N；无候选用内置 10 条 `builtin`。
- 落库 `reply_draft`：message_id=最近 inbound、conversation_id、draft_text、degraded、`evidence_refs`（JSONB 真正落库）、`fallback_reason`（degraded 时非空）、`latency_ms`、template_id、status=draft；`degraded=true` 时 DB CHECK 强制 fallback_reason。
- 发送门禁：带 `draft_id` 发送时读取 `reply_draft.degraded/evidence_refs`；降级草稿直接 409，不进发送链；非降级草稿 evidence_refs 为空也拒绝。
- 返回 `draft_id/text/degraded/degraded_reason/latency_ms/expires_at/evidence_refs/template_id/suggested_templates`。

## 6. 发送（B）与报价（C）

### 6.1 `POST /replies/send`

- 必须 `approval_id`：action=`send_reply`、platform 匹配、status=approved/approved_with_edit、未过期、level=B、`target_hash=canonicalHash({conversation_id,text})`、四眼（decided_by ≠ created_by/executor）。
- `(conversation_id, outbound_idempotency_key)`：
  - 先查已有 message：sent/sending → 200 `deduped=true`，不再次调用 adapter；
  - 新建 message status=`sending` 占位，唯一冲突（并发双击）→ 读现有行返回 deduped。
- kill switch `taskType=message`；通过 t9 `PlatformWritePort.preview('message.send')` dry-run（PDD/1688 注册表接口），响应 `contract_unverified=true`。
- 成功：message status=sent、conversation.last_message_at、approval executed、outbox message.created、audit `message.send`（irreversible=true，after 含 operation_level=B）。
- 返回 `message_id/status/platform_msg_id(null dry-run)/deduped/contract_unverified`。

### 6.2 `POST /inquiries/:id/quote`

- 仅 1688；`PriceTiersV1` 由 core `validatePriceTiers` 校验（首档=min_order_qty、递增、价格不增）。
- C 级审批：action=`send_quote`、level=C、target_hash=`canonicalHash(quoteTargetPayload)`、四眼、admin 决策。
- 必须 `confirm_token`（5 分钟、一次性、绑 approval/user/action=`inquiry.quote`/target_hash）；`POST /inquiries/:id/confirm-token` 签发。
- `message.content_type='quote'`（t24 已加枚举），结构化报价单（quote_no/valid_until/items.qty_tier/min_order_qty/tax/shipping/drop_ship）放 `message.attachments`；`quote_id=message.id`。
- 适配器 dry-run `inquiry.quote`（1688 `quote.create`）；返回 `contract_unverified=true`，无真实平台报价号。
