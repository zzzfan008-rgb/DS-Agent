## 二、启动与停止

```bash
cd /d/DSSAAS

# 启动 API（必须在仓库根目录，否则读不到 .env）
nohup node apps/api/node_modules/tsx/dist/cli.mjs apps/api/src/index.ts > /tmp/api3.log 2>&1 &

# 启动 Web
cd apps/web && API_INTERNAL_URL=http://127.0.0.1:3010 nohup npx next dev -p 3000 > /tmp/web.log 2>&1 &

# 停止
pkill -f "tsx.*src/index.ts"; pkill -f "next dev"
```

**注意**：API 必须从仓库根目录启动，因为它按 cwd 找 `.env`。

## 七、已知问题（我修了一个）

**已修**：登录页显示"系统维护中"且按钮禁用。
- 原因：API 返回 `status: "healthy"`，前端只认 `"ok"`，枚举不一致。
- 影响：**任何人都无法登录**。
- 修复：`apps/web/src/lib/contracts.ts` 与 `LoginScreen.tsx` 接受 `healthy`。
- 这个 bug CI 没抓到，因为没有前端 E2E 覆盖登录页。

**未修（需要你确认优先级）**：
- `pnpm e2e` 脚本依赖 Docker，本机无 Docker 时失败；已确认可直接跑 `node apps/api/node_modules/tsx/dist/cli.mjs scripts/e2e/full-chain.mjs`。
