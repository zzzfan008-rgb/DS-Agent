## 0. 结论先行

1. **M1 只交付可运行骨架，不交付可决策审批**：登录、全局壳层、12 路由占位、权限可见性、审批中心**只读**列表与详情、统一四态、SSE 占位。
2. **审批数据采用"真实 API 优先 + 404 演示回退"**：请求 `GET /api/approvals` 若返回 404（端点未实现）则使用内置演示数据，并在页面顶部与详情内显示醒目的 `DEMO` 横幅；网络错误/500 **不**回退，直接走错误态。这样验收可浏览，又不会把"接口失败"伪装成成功。
3. **视觉方向**：深色左侧栏 + 浅色工作区，风险色严格复用 docs/13 §5.1 的 A/B/C token；A/B/C 用"颜色 + 图标 + 文字"三重编码。
4. **权限从前端契约来**：页面可见性与动作可见性一律读 `GET /me.permissions[]`，**不按角色名硬编码**；无权限入口不渲染，越权直达 URL 渲染无权限态（不泄露对象存在性）。
5. **SSE 在 M1 是"可观测的占位"**：不假装已连通。连接灯默认显示"实时未接入（M1 占位）"，`useRealtimeStream` 已按 docs/12 §7 实现连接/退避/降级骨架，M4–M5 打开开关即可接真流。

### 2.3 权限实现（前端侧）

```text
GET /api/me
   └─ permissions[]  ──┬─→ <AppShell> 过滤 nav（无键即不渲染）
                       ├─→ guardPage(permission)  → 有则渲染，无则 <ForbiddenState>
                       └─→ <Can permission="...">  → 动作级显示/隐藏
```

- 页面级：`guardPage('audit.read')` 这类 Server Component 包装，403/缺失统一渲染 `ForbiddenState`，文案固定"无权访问或不存在"（docs/13 V8）。
- 动作级：M1 只有"登出/重试/筛选"等无需特权的动作；审批决策按钮**不渲染为可点击**，只显示只读说明。
- 权限刷新：登录后取一次；收到 401 跳登录；收到 403 刷新 `/me` 并重渲染（docs/13 V7 骨架已留 hook）。

### 3.2 字体与排版

- 字体栈：`-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", system-ui, sans-serif`（不引外部字体，离线可构建）。
- 基数 14px / 行高 1.55；页面标题 20/28 semibold；卡片标题 15/22；辅助 12/18；ID 用 `ui-monospace, "SFMono-Regular", Consolas, monospace`。
- 间距 4px 网格；圆角 8px（卡片）/ 6px（输入/按钮）；阴影仅弹层使用。

### 3.3 断点（对齐 docs/13 §8.1）

| 宽度 | 侧栏 | 审批中心 | 表格/卡片 |
|---|---|---|---|
| ≥ 1536 | 240px 常驻 | 队列 380 + 详情 flex | 全列 |
| 1280–1535 | 220px 常驻 | 队列 340 + 详情 flex | 隐藏次要列 |
| 1024–1279 | 72px 图标栏 | 列表/详情切换 | 转卡片 |
| 768–1023 | 底部 4 tab + "更多" | 单栏 | 卡片 |
| < 768 | 底部 tab | 单栏，仅查看 | 卡片 |

M1 实现 5 档断点；视觉稿给 1440 / 1024 / 390 三个代表宽度。

### 3.4 可访问性基线

- 焦点环 `2px solid var(--brand-600)` + `2px offset`，全局不 `outline:none`。
- 跳转链接"跳到主内容"；侧栏为 `<nav aria-label="主导航">`；当前项 `aria-current="page"`。
- 风险级别不只靠颜色：图标（↺ / ⚠ / ⛔）+ 文字（"A · 可逆"等）。
- 倒计时 `aria-live="polite"`，且只在跨越阈值（2h / 30min）时播报，不每秒播报。
- 快捷键 `?` 面板列出当前页可用键；在 `input/textarea/contenteditable` 与 IME 组合输入期间不触发单键快捷键。

### 5.3 状态与文案

| 场景 | HTTP | UI |
|---|---|---|
| 提交中 | — | 按钮 spinner，字段与按钮 disabled，阻止重复提交 |
| 账号/口令错 | 401 | 表单级红色 alert："账号或口令不正确"（不区分账号是否存在）；**不**清空 email |
| TOTP 缺失/错误 | 401 `detail.totp_required` | 展开 TOTP 字段并聚焦；文案："请输入 6 位动态码" |
| 账号锁定 | 423 | alert 显示 `detail.locked_until` 剩余时间（"请于 14:32 后重试"），禁用提交 |
| 限流 | 429 | alert 显示 `Retry-After` 倒计时；到点自动恢复 |
| 系统维护 | health `down` | 顶部黄条"系统维护中"，禁用登录；health `degraded` 仅黄字提示 |
| 网络失败 | — | alert："无法连接服务（{request_id}）"，保留输入 + 重试 |
| 成功 | 200 | 写入会话 Cookie（服务端）→ `router.replace(safeReturnUrl)`，刷新 `/me` |

`return_url` 只接受同源相对路径（以 `/` 开头且不以 `//` 开头），否则回 `/`。

## 10. 数据与契约约定

### 10.1 认证（已可用，t2）

```text
POST /api/auth/login  {email, password, totp_code?}
  → data{user{id,name,role}, csrf_token, expires_at, must_change_password}
GET /api/me           → data{id,name,role,org_id,permissions[],delegations[],quotas{}}
POST /api/auth/logout → 需 X-CSRF-Token（读 dssaas_csrf Cookie）
```

- 浏览器侧一律同源相对路径 `/api/...`；开发期由 Next rewrite 到 `http://127.0.0.1:3001`，生产由 Caddy `/api/*` 反代（infra/Caddyfile 已就位）。
- 服务端组件取 `/me` 时用 `API_INTERNAL_URL` + 转发 `cookie` 头，避免依赖 rewrite。
- 所有响应按 `{request_id, data}` / `{request_id, error{code,message,retryable,next_action,detail}}` 解析；错误码文案映射见 docs/12 §4。
- CSRF：M1 只有登出是写请求；从 `dssaas_csrf` Cookie 读值写 `X-CSRF-Token`。

### 10.2 审批（M1 演示回退）

| 请求 | 真实契约 | M1 行为 |
|---|---|---|
| `GET /api/approvals?status&level&platform&overdue&assignee&sort` | docs/12 §3.5，返回 `items[] + meta{pending_count,oldest_wait_minutes,next_cursor}` | 404 → 演示数据（6 条：A×2/B×2/C×2，含超时/批量/临期样本）；其它错误 → 错误态 |

| `POST /api/approvals/:id/decide` | M4 | **不实现、不发送** |

### 10.3 类型与边界

- 前端类型集中：`src/lib/contracts.ts`（envelope、Me、ApprovalList/Detail、错误码）。
- 不引入 `@dssaas/core` 到浏览器（避免把服务端矩阵打进 bundle）；页面权限键以字符串常量集中维护，注释指向 `packages/core/src/authz/matrix.ts` 作为唯一真源。

- 金额显示统一 `formatCents()`（分 → "¥1,234.00"），不在页面里做浮点运算。
