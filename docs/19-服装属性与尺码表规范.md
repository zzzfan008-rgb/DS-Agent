### 0.2 六条铁律

1. **事实不进模型**：色卡、尺码、测量值、成分、洗护、资质只来自导入/ERP/人工/平台同步（`ck_source_kind` 无模型取值），模型只能改写措辞。
2. **编码不承载判断**：`color_id` / `size_code` 是主键组成部分，展示名（"卡其色""2XL"）不参与业务判断。
3. **单位与精度唯一**：长度一律 `cm`、步进 `0.5`；成分百分比一律整数；身高 `cm`、体重 `kg`、克重 `g`。
4. **同源同版本**：尺码表数据、尺码表图、客服话术、知识库切片必须同 `version_no`；图与数据 `checksum` 不一致即禁止发布。
5. **映射先验证**：`platform_attribute_mapping.status='verified'` 是用映射的唯一条件；`draft` / `stale` 一律不得进入发布报文。
6. **平台值不猜**：平台侧取值只能来自字典快照；未核验字段写"待核实"，不以经验值填充，不因"看起来差不多"放行。

## 1. 内部色卡与平台色卡 ID 映射
`color_id` 是 SKU 自然主键之一（`06` §4.2.2），只做标识、不做判断，格式 `{色系码}-{4 位序号}`。

| 项 | 规则 |
|---|---|
| 格式/序号 | `^[A-Z]{2}-[0-9]{4}$`，新码必带连字符；色系内 0001–9999 顺序分配，不含深浅/材质/季节/平台语义 |
| 色系码 | 15 个受控值（见下），由 `packages/core/src/vocab/color-family@1.json` 提供，新增需评审升版 |
| 展示名 | `color_name` 独立维护，改文案不动 `color_id`；不得用展示名反推编码 |
| 禁止 | 平台色卡 ID、拼音、英文名、Hex 色值充当 `color_id`；无连字符历史码只读兼容 |

色系码：`BK` 黑 · `WH` 白/本白 · `GY` 灰 · `BE` 米/杏/驼 · `BR` 棕/咖 · `RD` 红 · `PK` 粉 · `OR` 橙 · `YL` 黄 · `GN` 绿 · `BL` 蓝 · `PR` 紫 · `GD` 金/金属 · `SV` 银 · `MC` 多色/印花。
### 1.1 映射表结构
映射落 `platform_attribute_mapping`（`06` §4.2.6），`attr_path='color'`、`internal_field='product_sku.color_id'`；作用域 = 平台 × 叶子类目 × 属性。

| 字段组 | 规则 |
|---|---|
| `platform` / `platform_category_id` | 必填；类目必须 `is_leaf=true`，禁止父类目映射 |
| `internal_value` | 内部 `color_id`；同作用域内一个色号只能命中一行 |
| `platform_value_id` / `_name` / `extra` | 平台色卡 ID/展示值只能来自 `platform_category.raw` 最新快照；`extra` 存 `snapshot_version`、`validated_at`、`merge_reason`、`fallback` |
| `status` / `source` | 仅 `verified` 可用于发布；`draft` 待核验、`stale` 快照已变 |

### 1.2 冲突处理
| 冲突 | 判定 | 处置 |
|---|---|---|
| 一内部值对多平台值 | 同作用域第 2 行 | 拒绝写入，保留先验证者，后到行 `draft` 待裁决 |
| 多内部值对一平台值 | 两 `color_id` 指向同一平台 ID | 允许；须 `extra.merge_reason`，且两码同色系 |
| 平台值消失 | 快照查不到该 ID | 整行置 `stale` + P0 工单，发布门拦截，禁止猜替 |
| 跨色系并档 | 如墨绿 → 黑 | 禁止；降级也不得跨色系 |
### 1.3 平台侧无对应色卡的降级
按 D1→D2→D3 顺序尝试，不得跳步；全程留痕，禁止填假 ID。

| 顺序 | 路径 | 条件 | 结果 |
|---|---|---|---|
| D1 | 同色系粗粒度值 | 同色系标准值存在且色差可接受 | `extra.fallback='coarse'`，人工 `verified` |
| D2 | 自定义颜色文本 | 该类目 `color` 为 `text` 且快照允许自定义 | `platform_value_id=null`，名称取 `color_name` |
| D3 | 该平台不发布 | 仅 `enum` 且无值可用 | SKU 置 `listing_skip` + 工单；不得裸提交 |
## 2. 尺码编码规范
`size_code` 词表封闭（`06` §4.2.2 正则）；新增码型必须扩词表 + 升 DB 约束版本，禁止自由文本。

| 码型 | 允许值 | 用途与规则 |
|---|---|---|
| 字母码 | `XXXS` `XXS` `XS` `S` `M` `L` `XL` `XXL` `XXXL` `4XL` `5XL` | 常规分码；`2XL`/`3XL` 为别名，入库前归一为 `XXL`/`XXXL` |
| 数字码 | `[0-9]{2,3}`：童装身高 90–160、裤装腰围 26–40 | 语义由 `size_system` + 品类决定，同表不得混用 |
| 均码 | `ONE` | `size_system='one_size'`，整表仅 1 行（Schema 强制） |
| 加肥加大 | `4XL` / `5XL`；更大走码型扩展评审 | 禁止 `6XL`、`FREE`、`均码加大`，均无法入库 |

别名归一（导入层完成）：`2XL→XXL`、`3XL→XXXL`、`加大→XL`、`加加大→XXL`、`特小→XS`、`均码/自由码/F→ONE`；`00` §13.2 示例中的 `2XL` 同按此归一，解析器不得因此放宽正则。国标号型 `170/88A` 不进 `size_code`，写入映射行（`platform_value_name` 或 `extra.gb_size`）。

| 内部码 | 男上装号型（GB/T 1335，内部约定） | 女上装号型 | `size_order` |
|---|---|---|---|
| XS | — | 155/80A | 30 |
| S | 165/88A | 160/84A | 40 |
| M | 170/92A | 165/88A | 50 |
| L | 175/96A | 170/92A | 60 |
| XL | 180/100A | 175/96A | 70 |
| XXL | 185/104A | — | 80 |
| XXXL | 190/108A | — | 90 |
| 4XL / 5XL | 按净体围度递推 | 同左 | 95 / 99 |

`size_order`：字母码取上表；数字码按数值升序映射 `10,20,…`；`ONE=0`；同表唯一且严格递增；展示只认 `size_order`，不认字符串（`10` 不会排在 `9` 前）。
## 3. 尺码表结构、部位与测量
`measurements` 只允许 `06` §6.1 的 12 个键；键名即口径，禁止同义名（"胸宽""衣尺寸"一律拒绝）。

| 部位 | 测量方法（成衣平铺） | 公差 |
|---|---|---|
| 衣长 | 后领中点垂直至下摆底边（后中） | ±1.0 |
| 胸围 | 袖窿最低点下 2cm 水平围量一周（全周） | ±1.5 |
| 肩宽 | 左右肩点（肩袖缝）直线距离 | ±0.5 |
| 袖长 | 肩点沿袖中线至袖口边 | ±0.5 |
| 腰围 | 腰节最窄处水平一周（全周） | ±1.5 |
| 臀围 | 臀最丰满处水平一周（全周） | ±1.5 |
| 下摆 | 下摆边水平一周（全周） | ±1.0 |
| 裙长 | 腰口上沿（含腰头）垂直至裙摆底边 | ±1.0 |
| 裤长 | 腰口上沿（含腰头）沿侧缝至脚口 | ±1.0 |
| 脚口 | 脚口边水平一周 | ±0.5 |
| 大腿围 | 裆底点下 2.5cm 水平一周 | ±1.0 |
| 领围 | 领口扣好/拉合后弧线一周 | ±0.5 |
### 3.1 单位、精度与量体基准

| 项 | 规则 |
|---|---|
| 单位/精度 | 一律 `cm`、`0.5` 步进；体重 `kg`、身高 `cm`、克重 `g`；显示整数省略 `.0` |
| 围度口径 | 存**成衣全周**；平台要半围时只在映射 `extra.display_divisor=2` 转换，不改主数据 |
| 量体基准 | 样衣与量产同版同料；平铺静置 ≥30 分钟、不拉伸、扣好拉合；每部位测 2 次取均值，差 >0.5 复测 |
| 洗后/弹性 | 默认测洗前；测洗后须 `fit_note` 注明；弹性面料公差可加 0.5cm，但不得静默放宽 |

### 3.2 品类必测部位（`L1-SIZE-003` 口径）
`category_code` 格式 `^[A-Z][0-9]{4}(\.[0-9]{1,3})?$`（`06` §4.2.1）：第 1 位品类域（A 上装 / B 下装 / C 裙装 / D 外套 / E 内衣家居 / F 配饰 / G 泳装防护），第 2–3 位人群（01 男 / 02 女 / 03 中性 / 04 童 / 05 婴幼），第 4–5 位品类序号，`.NNN` 为细分并继承父级部位。

| 类目 | 含义 | 必测 | 建议 |
|---|---|---|---|
| `A0101` | 男 T 恤 | 胸围、衣长 | 肩宽、袖长 |
| `A0202` | 女衬衫 | 胸围、衣长 | 肩宽、袖长、领围 |
| `B0211` | 女牛仔长裤 | 腰围、裤长 | 臀围、大腿围、脚口 |
| `C0221` | 连衣裙 | 胸围、裙长 | 腰围、臀围 |
| `D0232` | 女羽绒服 | 胸围、衣长 | 肩宽、袖长、下摆 |
| `E0201` | 女文胸 | 胸围（下胸围入 `extra_measures`） | 肩宽 |
| `G0201` | 泳衣 | 胸围、衣长 | 腰围、臀围 |

`extra_measures` 最多 6 项、键名 2–6 个汉字（Schema 限制），仅补上表未覆盖部位（下胸围、袖口、开衩长）；同商品同版本键名必须一致。
## 4. 建议身高体重区间规则
`recommend_*` 只能由成衣尺寸/试穿数据推导，不得由模型生成；四字段必须成对出现（`06` §6.1 `dependentSchemas`）。

| 步骤 | 规则 |
|---|---|
| 1 松量 | 按 `product.fit` 取成衣−净体松量：修身 胸围 6–8 / 腰围 2–4cm；常规 10–14 / 4–6cm；宽松 16–20 / 8–10cm，各取中值 |
| 2 净体 | 净胸围 = 成衣胸围 − 松量；净腰围 = 成衣腰围 − 松量；按 0.5 取整 |
| 3 身高 | 用净体尺寸查 `gb-body@1.json` 得号型档（5cm 一档）；区间 = 档位 ±5cm，取整并夹在 [100,230] |
| 4 体重 | 同表得体重区间；无表时按 BMI 18.5–24.0 反推 `W∈[18.5×H²/10000, 24×H²/10000]`，再与围度档 ±2kg 取交集 |
| 5 试穿优先 | 有试穿记录时以试穿者实测 min–max 为准，外扩 2cm/2kg；无试穿才用 3–4 步 |

| 校验 | 规则 | 失败提示 |
|---|---|---|
| 方向 | `min < max`，均为整数 | "身高/体重区间上限必须大于下限" |
| 单调 | 按 `size_order`，`min` 与 `max` 均严格递增，不得包含 | "后一码建议区间未高于前一码" |
| 衔接 | `min_{i+1} − max_i ∈ [−2,2]`：允许 1–3 个单位重叠、最多 1 个单位空档 | "相邻码之间空档/重叠过大" |
| 合理 | BMI 反算体重落 15–32；不超 Schema 的 100–230cm / 25–200kg | "建议体重与身高不匹配（BMI 异常）" |
| 覆盖 | 多码整表身高跨度 ≥20cm 或体重跨度 ≥15kg（均码除外） | "建议区间覆盖过窄，无法支撑分码" |

**重叠区口径**：`min_{i+1} ≤ max_i` 时，文案统一写"重叠区建议选大一码"，不得两边都推荐；推荐结论受 `L1-SIZE-001` 约束。**平台差异**：双平台是否提供结构化"建议身高体重"属性尚未核验，一律先渲染进尺码表图；确有字段时按 `attr_type='range'` + `extra{min,max,unit}` 映射，核验前不得写死字段名。

## 5. 面料成分录入规范
`materials` 结构见 `06` §6.2；百分比**整数**、合计 **100**、按占比降序，由 DB 函数与 JSON Schema 双重强制。

| 规则 | 内容 |
|---|---|
| 条数/百分比 | 1–8 条；1–100 整数，禁止小数、区间、"约"；合计必须 =100 |
| 排序 | 按 `percent` 降序；并列时主料在前 |
| 列名 | 占比 ≥5% 的纤维必须单独列名；<5% 可并为"其他纤维"，合计 ≤5% 且仍凑满 100 |
| 名称 | 只用 `06` §6.2 `fiber_name` 枚举；俗称在导入层归一，不落库 |
| 角色 | `note` ∈ 主料/辅料/里料/填充/装饰；主料/里料/辅料/装饰须与 `fabric_composition.role` 对应（`L1-CMP-003`） |
| 一致 | 与质检报告/供应商资料逐项一致；文案引用受 `L1-CMP-001` 约束 |

| 俗称/变体 | 标准名 | 俗称/变体 | 标准名 |
|---|---|---|---|
| 涤纶、聚酯 | 聚酯纤维 | 尼龙 | 锦纶 |
| 莱卡、弹性纤维 | 氨纶 | 人造棉、粘胶 | 粘纤 |
| 天丝 | 莱赛尔纤维 | 莫代尔 | 莫代尔纤维 |
| 真丝 | 桑蚕丝 | 山羊绒 | 羊绒 |
| 精梳棉、有机棉 | 棉 | 亚麻 | 亚麻 |

混纺文本由数组生成：`聚酯纤维62%、棉33%、氨纶5%`（名称+整数，顺序同数组）；平台成分字段若为自由文本，必须复用生成结果，禁止手写第二份。**禁止**"涤纶"、"棉+氨纶"（缺百分比）、"约 60% 棉"、"其他 100%"。

## 6. 洗护说明规范
`product.care_instructions` 固定五槽位 + 注记；槽位缺失视为未录入，文字由码表生成，详情页/客服/知识库同源（`06` §4.2.1）。

```json
{"wash":{"code":"W40","text":"40℃ 机洗，常规程序","temp_c":40},"bleach":{"code":"BNONE","text":"不可漂白"},
 "dry":{"code":"DHANG","text":"悬挂晾干"},"iron":{"code":"I150","text":"熨斗底板最高 150℃"},
 "dry_clean":{"code":"DCP","text":"常规干洗"},"note":"深浅色分开洗涤","source":"supplier"}
```

| 类别 | 代码 | 中文口径 |
|---|---|---|
| 水洗 | `W30`/`W40`/`W60`/`WHAND`/`WNONE` | 30/40/60℃ 常规机洗；手洗 ≤40℃；不可水洗 |
| 漂白 | `BOXY`/`BCL`/`BNONE` | 仅氧漂；仅氯漂；不可漂白 |
| 干燥 | `DHANG`/`DFLAT`/`DSHADE`/`DTUMBLE_LOW`/`DTUMBLE_NONE` | 悬挂晾干；平摊晾干；阴干；翻转干燥低温；不可翻转干燥 |
| 熨烫 | `I110`/`I150`/`I200`/`INONE` | 底板 ≤110/150/200℃；不可熨烫 |
| 干洗 | `DCP`/`DCF`/`DCNONE` | 常规干洗（P）；缓和干洗（F）；不可干洗 |

| 默认组合（模板，须人工确认） | 水洗 | 漂白 | 干燥 | 熨烫 | 干洗 |
|---|---|---|---|---|---|
| 棉 ≥60% | W40 | BOXY | DHANG | I150 | DCP |
| 聚酯 ≥60% | W40 | BNONE | DHANG | I110 | DCP |
| 羊毛 ≥30% | WHAND | BNONE | DFLAT | I110 | DCP |
| 桑蚕丝 ≥30% | WHAND | BNONE | DSHADE | I110 | DCP |
| 氨纶 ≥5% | W30 | BNONE | DHANG | I110 | DCNONE |

规则：① 码表外代码拒绝；② 默认组合只是录入模板，确认后写库，`source` 不得为模型；③ "不可水洗"不得同时带水温；④ 五槽位齐全才允许发布；⑤ 洗护图/文字/知识库切片须同 `version_no`（铁律 4）。

## 7. 类目资质字段清单
`product.qualification` 为对象，字段固定；平台要求来自 `platform_category.qualification_requirements` 快照，未核验项不得写成必填。

| 字段 | 类型 | 必填 | 规则 |
|---|---|---|---|
| `safety_category` | enum A/B/C | 是 | GB 18401：婴幼儿 A、直接接触 B、非直接 C |
| `execution_standard` | string | 是 | 产品执行标准号（如 `GB/T 22849`），与检测报告一致 |
| `fiber_label` | string | 是 | 纤维含量标识标准，默认 `GB/T 29862` |
| `reports[]` | array | 是 | 质检报告：`type`、`report_no`、`issuer`、`issued_at`、`valid_until`、`asset_ids[]`、`status` |
| `authorizations[]` | array | 否 | 商标注册证/授权链路：`brand`、`type`、`valid_until`、`asset_id` |
| `registrations[]` | array | 否 | 备案/许可：`type`、`no`、`valid_until`、`asset_id` |
| `checked_at` / `checked_by` | `timestamptz` / `uuid` | 是 | 最近一次人工核验时间与人 |

| 状态 | 判定 | 发布门禁 |
|---|---|---|
| `valid` | 必填齐全且全部 `valid_until ≥ as_of + 30 天` | 放行 |
| `expiring` | 任一资质 30 天内到期 | 放行 + 告警，到期前更新 |
| `expired` | 任一必填资质过期 | 拦截（`L1-QUA-001`） |
| `missing` | 必填缺失或附件非 `approved` | 拦截（`L1-QUA-002`） |
| `unknown` | `qualification_requirements` 为空/未核验 | 拦截，商品置 `qualification_unknown`（`01` G1） |

上架包对应：`listing.qualification` ← `product.qualification` 同名字段；附件只传 `asset_id`，不传 URL；有效期按 `Asia/Shanghai` 判定；资质变更须升 `product.fact_version` 并重审批。
## 8. 尺码表图片渲染规范
尺码表图只能由 `size_chart` 有效版本渲染（`10` §8 定模板变量与画布），本规范补充版式与命名；禁止手填、Excel 截图、AI 生成。

| 项 | 规则 |
|---|---|
| 画布 | 宽 750px，高自适应，单图 ≤3000px；超长按尺码行分页，最多 2 张 |
| 行列 | 首列固定"尺码"；列序 = 必测部位（§3.2 顺序）→ 建议部位 → 建议身高 → 建议体重；列数 ≤10 |
| 行 | 按 `size_order` 升序；斑马纹 `#F7F7F7`；行高 44px；建议区间缺失整列隐藏，不补 0/— |
| 字号 | 标题 34 / 表头 24 / 单元格 24 / 脚注 20（思源黑体随镜像打包，禁用系统字体） |
| 单位 | 表头写一次 `胸围(cm)`；数值 0.5 步进，整数省略 `.0`；禁止在单元格重复单位 |
| 颜色 | 主色 `#1F2329`，当前推荐尺码强调 `#D4380D`，背景纯白 |
| 脚注 | 固定"手工测量存在 1–3cm 误差，建议结合自身尺寸选择"；不得改写为承诺 |
| 导出 | PNG 无损；`chart_750` 必需、`chart_1200` 可选；单文件 ≤1.5MB |
| 命名 | `chart_{data_version}.png`，`data_version=v{YYYYMMDD}T{HHMMSS}Z`；同版本复用同一文件 |
| 一致性 | `render_spec_hash` = sha256(模板版本+排序后数据+字体版本)；图 `data_version` 必须等于 `size_chart` 版本，否则 `invalid_fact` |

## 9. 平台属性字典映射表模板
一条映射 = 平台 × 叶子类目 × `attr_path` × 内部值；字段与约束以 `06` §6.3 为准，下表为录入/导出模板。

| 模板字段 | 取值 | 说明 |
|---|---|---|
| `platform` | `pdd` / `1688` | — |
| `platform_category_id` | uuid | `platform_category.id`，非平台原始类目串 |
| `attr_path` | `color` / `size` / `material` / `season` / `fit` / `min_order_qty` … | 平台属性路径，小写 |
| `attr_type` | enum/text/number/bool/range/multi_enum | range 必须带 `extra.min/max` |
| `internal_field` | 四表白名单（`product`/`product_sku`/`size_chart`/`fabric_composition`） | 越界拒绝（安全边界） |
| `internal_value` / `platform_value_id` | 内部值 / 平台值 id | enum 必须有 id；text 可空 |
| `extra` | snapshot_version、min/max、display_divisor、gb_size、merge_reason | 平台特有语义只放这里 |
| `status` / `verified_at` / `verified_by` | draft/verified/stale | 写入门只认 `verified` |

| 平台 | 典型属性（待核验，以快照为准） | 内部来源 |
|---|---|---|
| 拼多多 | 颜色分类、尺码、材质成分、适用季节、袖长、领型、厚薄、版型、安全类别、执行标准 | `product_sku.color_id/size_code`、`fabric_composition`、`product.attributes`、`qualification` |
| 1688 | 颜色、尺码、面料成分、起批量、阶梯价、混批、货号 | `color_id/size_code`、`materials`、`product_sku.min_order_qty`、`price_tiers`、`extra.mix_batch_allowed`、`spu_code` |

**维护流程**（平台字典快照更新即触发）：① 拉取类目/属性快照并存 `raw` + `fetched_at`；② diff 出新增必填/值域删除 → P0 工单；③ 受影响映射置 `stale`，禁止发布；④ 后台补映射并"验证"→ `verified`；⑤ 跑黄金集（§12）回归；⑥ 记录 `contract_version` 与变更日志。**漂移红线**：必填属性新增 24h 内未补齐，相关商品上架一律 `blocked`，不得沿用旧映射。

## 10. 三级校验规则
校验顺序固定 Schema → 业务 → 平台预检，前一级失败不进下一级；错误结构统一 `{code, field, expected, actual, hint}`。

| 级别 | 校验项 | 规则 | 失败提示/错误码 |
|---|---|---|---|
| L0 | 必填/类型 | 三份 Schema 用 ajv `strict` 校验 | `SCHEMA-001` 字段缺失/类型错；HTTP 422 `validation_failed` |
| L0 | 尺码词表 | `size_code` 命中正则；`one_size` 仅 1 行 | `SCHEMA-002` "尺码不在词表内" |
| L0 | 测量键 | 仅 12 键 + `extra_measures`≤6；0.5 步进、>0、≤250 | `SCHEMA-003` "部位名或精度不合法" |
| L0 | 成分 | 1–8 条、整数、合计 100、枚举内 | `SCHEMA-004` "成分百分比合计不等于 100" |
| L0 | 映射 | enum 必须有 `platform_value_id`；range 必须有 min/max | `SCHEMA-005` "平台值缺失" |
| L1 | 码集 | 尺码表码集 ⊇ `active` SKU 码集（`L1-SIZE-004`） | `BIZ-SIZE-001` "存在无尺码数据的 SKU" |
| L1 | 必测部位 | 按 `category_code` 校验（§3.2，`L1-SIZE-003`） | `BIZ-SIZE-002` "缺少品类必测部位：胸围" |
| L1 | 区间 | 单调、衔接、BMI 合理性（§4） | `BIZ-SIZE-003` "建议区间不单调/有空档" |
| L1 | 色卡映射 | 每个 `active` SKU 在目标平台有 `verified` 映射 | `BIZ-COLOR-001` "颜色未映射/映射未验证" |
| L1 | 成分一致 | 与质检报告一致；俗称/非词表名拦截（`L1-CMP-002`） | `BIZ-FAB-001` "成分与报告不一致或含俗称" |
| L1 | 洗护 | 五槽位齐全、代码在码表、不可水洗不冲突 | `BIZ-CARE-001` "洗护不完整或代码非法" |
| L1 | 资质 | 有效期/必填/附件审核态（`L1-QUA-001/002`） | `BIZ-QUA-001` "资质过期/缺失：质检报告" |
| L1 | 图表一致 | `media_asset.data_version` = `size_chart` 版本且 checksum 一致 | `BIZ-MEDIA-001` "尺码表图与数据版本不一致" |
| L2 | 类目必填 | 平台 `required_attrs` 全覆盖，`is_leaf=true` | `PLAT-ATTR-001` "平台必填属性未覆盖：袖长" |
| L2 | 映射状态 | 只允许 `verified`；`stale`/`draft` 一律拦 | `PLAT-ATTR-002` "映射未验证，禁止发布" |
| L2 | 资质要求 | 按 `qualification_requirements`（平台×类目）逐项查 | `PLAT-QUA-001` "平台要求资质未满足" |
| L2 | 值域快照 | 值 id 必须在当前快照；快照超 7 天告警 | `PLAT-DICT-001` "平台字典已变更，请重新验证" |

L2 失败在本地预检返回 422 `invalid_fact`（附 `repair_hints`）；平台实际驳回返回 `platform_reject` 并写 `listing.published_snapshot` 证据；禁止跳过 L0/L1 直连平台预检。

## 12. 验收与测试清单
- [ ] 色卡：15 个色系码无重复；`color_id` 全命中编码正则；无平台 ID/色值混入
