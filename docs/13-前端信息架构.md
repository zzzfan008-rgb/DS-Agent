## 1. 设计原则（可检查，不做口号）

| # | 原则 | 落地判据 |
|---|---|---|
| D1 | 页面即工作流，不做"仪表盘陈列" | 每页有且仅有一个主操作区；首屏可见"下一步做什么" |
| D2 | 事实可视化 | 任何 AI 产出旁必须显示事实来源 chips（主数据版本/知识库切片），不可点击跳转即视为缺陷 |
| D3 | 风险前置 | A/B/C 级别在**点击前**可见（列表行、详情头、按钮），不是确认框里才出现 |
| D4 | 四态齐全 | 每个数据区块都必须有 空/加载/错误/无权限 四种实现，缺一即 bug |
| D5 | 无权限即隐藏 | 无权限入口不渲染（不用 disabled 假装可用）；只读页面内的操作才用 disabled + 原因 |
| D6 | 键盘可用 | 客服"接会话→发送"≤ 7 键；审批 A/B 级 ≤ 5 键；所有快捷键有 `?` 面板 |
| D7 | 状态不撒谎 | "发送中/发布中/生成中"必须有真实状态来源；不确定态显示"结果未知，正在对账"，禁止猜测成功 |
| D8 | 不遮挡关键信息 | 不可逆警告、SLA 倒计时、额度提示不得被折叠/次要位置 |

## 2. 全局框架

### 2.1 12 个页面与导航

| # | 页面 | 路由 | 导航分组 | 最低角色 | 实时策略 |
|---|---|---|---|---|---|
| 1 | 登录 | `/login` | 独立（无壳层） | 公开 | 无 |
| 2 | 首页：待办/告警/今日动态 | `/` | 工作台 | viewer | SSE（告警/待办角标） |
| 3 | 商品库 | `/products`、`/products/[id]` | 商品与内容 | viewer（读） | 轮询 30s（列表） |
| 4 | 文案工作台 | `/copy` | 商品与内容 | viewer（读） | SSE（agent run） |
| 5 | 素材库 | `/media` | 商品与内容 | viewer（读） | SSE（`media.job`）+ 轮询兜底 5s |
| 6 | 客服工作台 | `/service` | 工作台 | viewer（读） | **SSE 优先**，断线 5s 轮询 |
| 7 | 询盘工作台 | `/inquiry` | 工作台 | viewer（读） | 同客服 |
| 8 | 审批中心 | `/approvals` | 工作台 | viewer（读） | SSE（`approval.*`） |
| 9 | 平台连接 | `/platforms` | 平台与模型 | viewer | 轮询 60s + 手动刷新 |
| 10 | 模型与供应商管理 | `/models` | 平台与模型 | viewer（前台）/ admin（后台） | 无（改配置下个请求生效） |
| 11 | 知识库管理 | `/kb` | 平台与模型 | viewer（读） | 轮询 60s |
| 12 | 运营看板 + 审计与设置 | `/ops`（tabs：`?tab=dashboard\|audit\|settings`） | 治理 | viewer（看板）/ admin（审计与设置） | SSE（看板指标 30s 快照） |

导航分组固定 4 组（工作台 / 商品与内容 / 平台与模型 / 治理），登录页独立。**不做二级折叠菜单**（12 项一屏可见），窄屏合并为底部 4 tab + "更多"。

### 2.2 全局壳层

| 区域 | 内容 | 规则 |
|---|---|---|
| 顶栏左 | Logo、当前组织、页面标题 | 标题来自路由，不写死 |
| 顶栏中 | 全局搜索（`/` 聚焦；商品/会话/审批/知识库四域，分组结果） | 搜索即命令面板入口 |
| 顶栏右 | 实时连接灯（绿/黄/红）、待办角标、告警铃、角色徽标、用户菜单 | 连接灯 tooltip 显示"最近心跳时间/重连次数" |
| 侧栏 | 4 组导航 + 当前页高亮 + 未读/待办计数 | 计数来自 `GET /me` + SSE 增量；> 99 显示 `99+` |
| 全局横幅 | kill switch 生效、平台不可用、SSE 中断、配额耗尽 | 4 类横幅可叠加，最多 2 行，右侧"详情/关闭（不可关闭致命项）" |
| 命令面板 | `Cmd/Ctrl+K`：跳页面、找商品、找会话、执行动作（新建文案/提交审批） | 动作项按权限过滤 |
| 全局 toast | 成功（绿）/失败（红，含 `request_id` 与重试）/进行中 | 失败 toast 停留 8s；含 `next_action` 按钮 |

### 2.3 四态统一规范（所有区块复用同一组件）

| 态 | 何时 | 必须包含 | 禁止 |
|---|---|---|---|
| 空态 | 数据为 0 且非筛选导致 | 一句"为什么空" + 主 CTA（如"导入商品"）+ 次链接（帮助） | 只写"暂无数据" |
| 筛选空 | 有筛选条件但结果 0 | "无匹配结果" + "清除筛选"按钮 + 保留当前筛选摘要 | 清空用户筛选 |
| 加载态 | 首屏或切换区块 | 骨架屏（形状贴合真实内容）；**延迟 300ms 后才显示**（避免闪烁）；超过 5s 加"仍在加载"与取消 | 全屏 spinner、空白页 |
| 错误态 | 请求失败 | 标题（发生了什么）+ 原因（`code` + `request_id`）+ 主按钮（按 `next_action`）+ 次按钮（复制错误信息/联系 admin） | 只弹 toast 不留现场 |
| 无权限态 | 403/隐藏路由直入 | "需要 {角色} 权限" + "申请路径" + 不显示任何业务数据 | 显示数据但禁用操作 |
| 局部失败 | 多区块页某区块失败 | 仅该区块显示错误，其余正常；顶部不整页报错 | 整页白屏 |

## 5. 审批中心：不可逆标红规则

### 5.1 级别视觉 token（主题不可覆盖）

| 级别 | 语义色 | 背景 | 标签文案 | 图标 | 边框 |
|---|---|---|---|---|---|
| A | `--risk-a: #237804` | `#F6FFED` | "A · 可逆" | ↺ | 1px `#B7EB8F` |
| B | `--risk-b: #D46B08` | `#FFF7E6` | "B · 不可撤回" | ⚠ | 1px `#FFD591` |
| C | `--risk-c: #CF1322` | `#FFF1F0` | "C · 不可逆" | ⛔ | 左 4px 实心红条 + 1px `#FFA39E` |

深色主题：A `#73D13D`、B `#FFA940`、C `#FF7875`（背景 `#2A1215`），对比度均 ≥ 4.5:1。**风险 token 单独一层**（`risk-*`），不受品牌色/主题色覆盖。

### 5.2 C 级卡片必须包含（缺一即不可提交）

| # | 内容 | 展示要求 |
|---|---|---|
| 1 | 级别徽标 + 图标 + 文字（不能只有颜色） | 首行固定位置 |
| 2 | 动作名（中文 + `action code`） | 如"更换主图（listing.replace_main_image）" |
| 3 | 影响面 | SKU 数、预估影响订单、价格变动幅度、活动状态（"命中 618 活动"） |
| 4 | 与平台现值 diff | 字段级左右对比，变更值高亮 |
| 5 | 不可逆声明 | 固定文案："提交后不可撤回；平台侧可能触发重新审核、搜索降权或活动中掉线，系统不提供回滚" |
| 6 | 建议执行窗口 | 如命中活动 → "建议预约至 02:00–05:00，或先下架再改" |
| 7 | 审批有效期倒计时 | `expires_at` 剩余时间（< 2h 转橙，< 30min 转红） |
| 8 | 双人信息 | 审批人 ≠ 执行人；显示两者姓名与时间 |
| 9 | 事实来源 | 主数据版本、尺码表版本、知识库切片（可展开） |
| 10 | 关联审计 | `request_id`、历史同类操作条数（"该商品近 7 天第 3 次改主图"） |

### 5.3 C 级交互序列（禁止简化）

1. 用户在详情点"批准并执行"→ 打开执行弹层（不是浏览器 `confirm`）；
2. 弹层内必须滚动阅读完整影响面（滚动到底才启用勾选框）；
3. 勾选"我已知晓该操作不可逆，且系统不提供回滚"；
4. 点击"确认执行"→ 请求 `POST /listings/:id/confirm-token` 获取一次性 token（绑 `target_hash` + `user_id`，TTL 5 分钟）；
5. 携带 token 执行；token 过期 → 重新获取，表单内容保留；
6. 执行后进入"执行中 → 回执"状态；失败显示分类与 `next_action`；
7. **禁止**：一键全部批准、跳过勾选、`Enter` 直接执行、把 C 级混入批量、把红色改成主题色。

### 5.4 批量与例外

| 场景 | 规则 |
|---|---|
| A 级批量 | 允许，单批 ≤ 50；批量条显示"取最高级别" |
| B 级批量 | 允许，单批 ≤ 50；每项仍落审计 |
| C 级批量 | **禁止在审批中心批量**；必须逐项执行（12 §3.6 单批 ≤ 10 的批量端点仅用于"下架"这类止损，且逐项 confirm） |
| 混级 | 禁止混批，提示拆单 |
| 批量拒绝 | 统一理由 + 可单项覆盖 |

### 5.5 可访问性与一致性

- 颜色 + 图标 + 文字三重编码，色盲模拟（deuteranopia）下仍可区分；
- 屏幕阅读器：卡片 `aria-label` 含"不可逆操作"；倒计时用 `aria-live="polite"`（避免每秒播报）；
- 打印/导出 PDF 保留红色与文字标签（`@media print` 强制 `color-adjust: exact`）；
- 同级列表内 C 级永远排在顶部（与 `sort=sla_due_at` 不冲突：先按级别分组，再按 SLA）。

## 6. 客服工作台：秒级提醒与 5 秒降级

### 6.1 提醒链路（入站 → 可见 ≤ 1s）

| T+1s | — | 若用户已在该会话：消息直接进入消息流并滚动到底 |
| T+5s | — | 若 5s 内仍未打开会话：列表行显示 SLA 倒计时（按平台首响规则，70% 转黄、90% 转红） |

要求：SSE `message.new` P95 < 1s；断线时降级为 5s 轮询（此时允许 p95 ≤ 6s，并在顶部横幅标注"实时连接中断"）。

### 6.2 5 秒降级状态机（草稿）

| 状态 | 触发 | UI |
|---|---|---|
| `idle` | 打开会话 | 输入框上方显示"按 e 生成草稿" |
| `requesting` | 按 `e` 或自动（可配）→ `POST /replies/draft`，`deadline_ms=5000` | 草稿卡骨架："AI 正在生成…（3s）"，带进度条 |
| `slow` | T+3s 未返回 | 骨架文案切"仍在生成…（5s 上限）"；"用模板"按钮提前可用 |
| `ready` | ≤5s 返回 | 显示草稿 + 事实 chips + `latency_ms`；焦点移到"接受"按钮 |
| `degraded` | T+5s 未返回，或返回 `degraded=true` | **立即**插入话术模板首条（可编辑），状态条黄底："AI 草稿超时，已切换话术模板（可用 ↑ ↓ 换一条）"；提供"重试 AI"；后台请求**不取消** |
| `late_ready` | 降级后 AI 结果到达 | **不覆盖**用户已输入/编辑内容；顶部轻提示"AI 草稿已就绪 · 点击替换" |
| `failed` | 5s 内明确失败（`quota`/`upstream_5xx`/`dsh_unavailable`） | 立即进入 `degraded`（不等 5s），状态条写真实原因（"模型额度不足，已用模板"） |

约束：
1. 5 秒是**P95 体验承诺**，不是乐观提示；超过即降级，不允许"再等等"；
2. 降级模板必须来自 `reply_templates`（已批准），不允许模型即兴；
3. 降级后仍可发送（模板本身已审批），不得因降级阻塞首响；
4. 草稿请求并发：每会话 1 个、每用户 3 个；超出排队不报错；
5. 指标：`draft_degraded_rate`（总纲 §16 草稿降级率）按日统计并在看板展示。

### 6.3 发送（确认 + 去重）

| 步骤 | 交互 |
|---|---|
| 1 | `Cmd/Ctrl+Enter` 或 `s`：若草稿未接受则先接受 → 弹出确认条（会话名、字数、"发送后不可撤回"） |
| 2 | 再按 `Enter` 确认（两次按键防误发；可在设置里改为一次） |
| 3 | 前端生成 `outbound_idempotency_key`（`conversation_id + 草稿版本 + 时间戳` 的哈希），重复点击复用同一键 |
| 4 | 请求期间气泡为 `sending` 占位（禁止重复提交、禁止编辑该气泡） |
| 5 | 成功 → `sent` + `platform_msg_id`；失败 → 气泡标红 + "重试/复制"；`conflict`（重复）→ 直接显示已发送结果 |
| 6 | 服务端在同请求内落 `approval`（内联审批，11 §6.5）与 `audit_log`，前端不需要额外"提交审批"步骤 |

### 6.4 断线与降级

| 现象 | 检测 | 交互 |
|---|---|---|
| SSE 断开 | 30s 无心跳 / `onerror` | 顶部黄条"实时连接中断，正在重连"；自动重连退避 1s/2s/4s/8s/15s |
| 连续 3 次失败 | 重连计数 | 切 5s 轮询；黄条文案改为"已降级为 5 秒轮询"；恢复后自动切回并绿 toast |
| 发送通道不可用 | 发送 5xx | 保留草稿与确认条，不清空；提示"未发出，草稿已保留" |
| 平台不可用 | `upstream_5xx` 连续 | 顶部红条；禁用"发送"但允许继续编辑与复制到剪贴板（剪贴板助手兜底） |

### 6.5 剪贴板助手边界

- 只写系统剪贴板（`POST /clipboard/push` 返回文本 → `navigator.clipboard.writeText`）；
- **不做** DOM 注入、按键模拟、自动切窗、自动粘贴到平台（总纲 §1.3 明令禁止）；
- 复制成功 toast 提示"已复制，请到平台窗口粘贴（Ctrl/Cmd+V）"；
- 剪贴板内容超过 2000 字截断并提示。
